# Regras

Sempre que uma funcionalidade for concluída:

Atualizar imediatamente o CHANGELOG.md.

Nunca apagar versões antigas.

## Sempre utilizar os grupos:

- Added
- Changed
- Fixed
- Removed
- Deprecated
- Security (caso exista)

Escrever em português.

Escrever pensando no usuário.

Não listar detalhes internos de implementação.

### Exemplo errado:

Refatorado CalendarEngine.

### Exemplo correto:

Melhor desempenho ao mover eventos entre datas.
