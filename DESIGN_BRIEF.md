# Cansche UI Design Direction

O Cansche não deve parecer um SaaS dashboard.

Referências:
- Linear
- Figma
- Airtable
- Google Calendar mensal
- VS Code

Objetivo:
Criar um editor de tempo de alta densidade.

Princípios:

1. A grade é o elemento principal.
2. Células devem ser compactas.
3. Usuário deve visualizar o mês inteiro sem scroll excessivo.
4. Priorizar informação sobre decoração.
5. Evitar cards grandes.
6. Evitar glassmorphism excessivo.
7. Evitar espaços vazios.

Ações em massa são prioridade.

A interface deve parecer uma ferramenta profissional usada diariamente.

Elementos:

- calendário ocupa 80% da tela;
- sidebar pequena para presets;
- toolbar contextual aparece somente quando há seleção;
- atalhos de teclado importantes;
- suporte para usuários avançados.
