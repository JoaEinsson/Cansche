# Vision

Este projeto não é um clone do Google Calendar.

Este projeto é um Editor de Calendários.

A prioridade absoluta é velocidade de edição.

Sempre preferir operações em lote.

Sempre preferir poucos cliques.

Sempre preferir simplicidade.

O Engine deve ser independente da interface.

A UI é apenas um cliente.

O projeto deve permanecer Offline First.

A sincronização é um detalhe de infraestrutura.

Nunca permitir que integrações definam a arquitetura do Engine.

A experiência do usuário deve lembrar mais um editor (Excel/Figma) do que uma agenda tradicional.
